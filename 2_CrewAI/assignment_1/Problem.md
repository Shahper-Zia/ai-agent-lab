# Objective: 
Create a Crew AI system for analysing logistics data and developing optimization strategies for a specific logistics industry problem, such as optimizing delivery routes or inventory management.

## Instructions 

### Define Roles 
Create two agents a Logistics Analyst and an Optimization Strategist.

### Define Tasks 
- Assign a task to the Logistics Analyst to research the current state of logistics operations, focusing on route efficiency or inventory turnover trends.
- Assign a second task to the Optimization Strategist to create an optimization strategy based on the insights provided by the Logistics Analyst.
Parametrize the Tasks so it is possible to provide a list of products to optimize.

### Build the Crew 
Set up the crew with the two agents and their tasks.Ensure each agent has a clear goal and backstory that aligns with their roles in logistics.
